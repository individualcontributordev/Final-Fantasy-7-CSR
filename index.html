FF7 CSR Patcher

Pick your NTSC-U PS1 .bin, choose a CSR / CSR+ / CSR++ disc patch, apply. Patching stays in your browser — files are not uploaded to a server.

  1. Use a clean NTSC-U (US) Disc 1 / 2 / 3 .bin (not an already-patched image).
  2. Select the matching patch in the dropdown (disc number must match).
  3. Click Apply patch — your browser downloads the patched .bin.
  4. Rename / edit your .cue so it points at the new .bin filename.

Disc images are large (~700 MB). Give the tab a minute; ignore any “file too big” warnings from the OS file picker if the file still selects.
